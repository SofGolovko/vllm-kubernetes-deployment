# vLLM Kubernetes Deployment
Проект предназначен для локального запуска языковой модели с использованием CPU и постоянного хранилища для файлов модели.

## Технологический стек
Kubernetes: Minikube.

Контейнеризация: Docker.

Inference engine: vLLM 0.32.0.

Режим вычислений: CPU-only.

Языковая модель: Qwen/Qwen2.5-1.5B-Instruct.

Python: 3.12.15.

## Docker-образ

Для создания собственного образа используется официальный CPU-образ vLLM версии 0.32.0, закреплённый по digest.

В Dockerfile предусмотрено:

использование CPU-сборки vLLM;
создание отдельного пользователя с UID/GID 2000;
запуск контейнера без прав суперпользователя;
подготовка каталогов для приложения и хранения модели.

## Сборка образа:

docker build -t vllm-custom:0.32.0 .


## Безопасность

В проекте предусматриваются следующие меры:

запуск контейнера от непривилегированного пользователя;
хранение токенов в Kubernetes Secret;
отделение параметров конфигурации от Docker-образа;
отказ от записи пользовательских запросов и ответов модели в логи;
регистрация фактов обращений к API без сохранения содержимого запросов и ответов.
